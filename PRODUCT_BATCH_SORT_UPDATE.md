# Product batch sorting update

The Product Batches toolbar now contains a sorting control beside the search field.

Available options:

- **Newest first** — newest `received_at` first.
- **Cheapest first** — lowest batch retail selling price first.
- **Expensive first** — highest batch retail selling price first.

The sort is applied after the current search filter, so searching for a product and changing the sort immediately reorders the matching batch rows. Equal prices fall back to newest receipt first.
