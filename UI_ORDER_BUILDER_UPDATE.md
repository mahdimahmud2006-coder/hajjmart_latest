# Order Builder UI update

This build intentionally changes only the requested POS/Social Commerce presentation:

- Retail/Wholesale selling-price selection now lives inside the Order Builder on both pages.
- The selector uses a translucent glass treatment with a sliding active pill.
- POS sticky positioning is applied to the complete summary column instead of only the cart, preventing the payment button from overlapping subtotal/total content while scrolling.
- Existing retail/wholesale pricing behavior, offline POS behavior, order logic, product sorting and backend functionality are unchanged.
